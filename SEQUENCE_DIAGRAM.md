# TravelBudgetPlanner — Sequence Diagram

## Main Planning Flow

```mermaid
sequenceDiagram
    participant UI as UI (React/Vite)
    participant BE as Backend (FastAPI)
    participant Gemini as Google Gemini (gemini-2.0-flash)

    %% 1. Load saved trips on startup
    UI->>BE: GET /destPackage
    BE-->>UI: list of DestinationPackage

    %% 2. Load friends list
    UI->>BE: GET /users
    BE-->>UI: list of User

    %% 3. Natural-language trip planning
    UI->>BE: POST /prompt - body: message string

    Note over BE,Gemini: Extract trip intent from free text
    BE->>Gemini: generate_content - extract departureDate, returnDate, destinations, activities - JSON only
    Gemini-->>BE: departureDate, returnDate, destinations, activities

    alt Dates are in the past or invalid
        Note over BE,Gemini: Date correction pass
        BE->>Gemini: generate_content - infer sensible future dates - JSON only
        Gemini-->>BE: corrected departureDate and returnDate
    end

    alt Destinations look ambiguous
        Note over BE,Gemini: Destination validation pass
        BE->>Gemini: generate_content - are these real travel destinations? - JSON
        Gemini-->>BE: valid flag and corrected destinations
    end

    BE-->>UI: PromptResponseModel - departureDate, returnDate, destinations, activities

    UI->>BE: POST /suggestions - departureDate, returnDate, destinations, activities

    Note over BE: Load pre-built package.json (generated by Worker pipeline)
    Note over BE,Gemini: Select best-matching destinations
    BE->>Gemini: generate_content - select matching destinations from available list - JSON array only
    Gemini-->>BE: selected destination names e.g. Rome, Florence

    BE-->>UI: Summary with list of DestinationPackage

    %% 4. Save a trip
    UI->>BE: POST /destPackage - body: DestinationPackage
    BE-->>UI: status ok

    %% 5. Delete a saved trip
    UI->>BE: DELETE /destPackage/:name
    BE-->>UI: status ok, removed 1
```

## Worker Pipeline (Offline — runs before the service starts)

```mermaid
sequenceDiagram
    participant W as Worker (claudio)
    participant SK as scikit-learn (NLP / Naive Bayes)
    participant TP as Teleport API (city data)
    participant FS as package.json (output file)

    W->>W: generate_accommodation.py - create 3 properties x 3 cities
    W->>W: generate_transport.py - create flights, trains, buses
    W->>W: generate_activities.py - create 4 activities x 3 cities

    W->>SK: user_profiler_scikitlearn.py - analyse transaction CSV (Greek text)
    SK-->>W: user profile scores 1-10: budget, cultural, nightlife, mobility, activity

    W->>TP: city_profiler_teleport.py - fetch city scores for Rome, Florence, Venice, Athens
    TP-->>W: city profile scores: budget_city, cultural_city, nightlife_city

    W->>W: destination_criteria.py - Euclidean distance: user affinity vs city profiles
    W->>FS: write package.json with ranked destination packages and itinerary details
```

## Error / Fallback Paths

| Scenario | Behaviour |
|----------|-----------|
| Gemini API fails on `/prompt` | HTTP 502 returned; UI shows error message |
| Gemini returns malformed JSON | Regex fallback extracts JSON from markdown block |
| Gemini date extraction fails | Secondary LLM call requests date correction |
| Gemini destination selection fails | All available destinations included in results |
| `/destPackage` GET fails | UI silently omits "Planned Trips" section |
